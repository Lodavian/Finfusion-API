# 交付与验收状态

本文件记录实现与实测的边界，不替代生产验收。

当前阶段仅做开发。当前电脑是开发机；部署、运维和真实券商联调在后续指定的另一台电脑上进行。本机 WSL 是否可用不作为开发阻碍或验收前提。

## 已实现

- 独立源码与 Git 仓库、项目内 Python 环境、依赖锁定和来源清单。
- 无 Casdoor 交互登录的 P-256 程序调用；管理员 JWT 单独保留。
- 客户端登记、批准、禁用、公钥轮换和三类权限；请求与事件隔离。
- 账户、持仓、美元购买力、订单、改单、撤单、请求查询及事件订阅。
- 自动行情准备、与行情无关的幂等摘要、未知结果对账、重启默认关闭及环境隔离。
- WSL2 节点安装/配置/备份/恢复/诊断源码；源项目的旧 Docker 路线未纳入。
- Python 示例、密钥生成器、OpenAPI 契约与中文部署说明。
