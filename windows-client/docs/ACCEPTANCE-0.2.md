1. `run-tests.ps1`，应全部通过；任何交易模拟只监听 127.0.0.1。
2. `run.ps1 --smoke-test --smoke-result build\dev.json`；检查报告布尔项全部为 true，桥接仅 action/get_state/key_operation/save_config。
3. `build-windows.ps1`，将 ZIP 移到中文、空格目录，执行相同 smoke 参数；不依赖项目 Python。
4. `build-installer.ps1`；仅编译，验证附带微软安装器签名，最终 Finfusion 安装器应为 NotSigned 内部候选。
5. 正常启动不自动连接。保存配置不得显示服务器连接成功。未认证、无账户、未知环境或 LIVE 不允许候选下单。
