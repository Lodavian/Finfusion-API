# 极速下单界面参考记录

Finfusion Client 0.1.1 的 Windows 原生窗口只读参考 [Lodavian/-](https://github.com/Lodavian/-/tree/680b5a8f2ce1a5c5830fc9e59ba4bf97735010dd) 的 static/index.html 与 static/styles.css。

| 元素 | 来源配色 / 桌面实现 |
|---|---|
| 背景 | #060b14 深蓝黑 |
| 正文 / 次要说明 | #f6f8fc / #8e9bb0 |
| 蓝 / 青强调 | #6ea8ff / #4de1e8 |
| 买入 / 卖出 / 待确认 | #50e4a7 / #ff6684 / #ffc96b |
| 卡片 | 深蓝背景、圆角、细边框，原生控件内容 |
| 顶栏 | 品牌、USD 购买力、连接及设置操作 |
| 交易 | 右侧卡片、市价/限价分段、整股数量、1/10/25/100 快捷键、买入/卖出按钮 |
| 账户数据 | 左侧持仓和订单卡片，订单详情及待确认请求切换 |
| 设置 | 相同深色卡片、输入框和蓝色保存按钮 |

保留已批准的客户端功能范围。界面没有加入盘口、行情、股票搜索、预计成交金额、本地风险上限或实盘开关。股票框只录入代码，购买力及订单状态只呈现服务器数据。网页的透明模糊、渐变光晕和动效简化为 Windows 原生的深色圆角卡片，不能声称像素一致。

小屏幕下输入区可滚动，买入/卖出始终固定可见；选择限价单时自动滚到限价输入位置。所有快捷键只修改数量，不发送命令。订单详情在独立深色窗口中显示，切换账户立即关闭。没有改变签名、交易指令、权限、幂等记录或恢复流程。

本次在临时数据下实际启动并捕获主窗口、设置窗口进行视觉检查，没有读取用户私钥或连接服务器。另有真实 Tk 控件验证分段切换、快捷数量、最小窗口下按钮可见性和原先的重复点击保护。
# 0.2 更新

当前主窗口为内嵌 WebView2。复用 FastOrder 680b5a8 原版 HTML 布局、CSS、动效和图标，JavaScript 数据层重写。下文 0.1 的 Tkinter 记录仅供历史参考。

品牌、客户端签名设置、服务器只读权限及待确认请求是必要差异。原版与候选以 1226×700 CSS 像素视口和模拟数据进行了截图核查，未宣称像素级完全相同。生产包不包含 tools/reference 视觉夹具和原券商后端。
