## 实现范围

- 原生桌面窗口；服务器地址、clientId、P-256 密钥生成/导入、公钥导出及分开的配置/鉴权/事件/交易就绪状态。
- 授权账户查询、单账户自动选择、多账户明确选择、持仓与 USD 购买力、订单列表/分页/详情、手动刷新。
- BUY/SELL、MARKET/LIMIT、整股数量、限价修改及撤单；客户端仅校验输入格式和呈现服务器门禁，不执行交易风控。
- 原样复制签名 SDK；实际发送使用同一签名实现、查询编码和 JSON 字节。HTTP/WebSocket 不跟随重定向，TLS 校验始终保留。
- 当前用户 DPAPI 私钥存储，受限用户数据目录，用户数据不写安装目录，不记录或显示私钥；导出的仅为公钥。
- 唯一幂等编号及不可变请求内容先写入 SQLite 再发送。每个交易指令最多发送一次，失败/超时/重启后只查询原请求，不生成新编号重发。
- 按账户保护重复操作，其他账户仍可操作；单实例、防重复点击、账户切换丢弃迟到数据、事件版本去重与断线补查。
- 服务器接收、券商接受、部分成交、成交、撤单请求中、已撤销、拒绝和待确认均显示中文及原始状态码。
