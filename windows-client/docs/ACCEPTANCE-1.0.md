## 1.0 自动化及本机窗口

1. `run-tests.ps1`：签名、防重放、权限、超时不重发、重启恢复、行情隔离及 LIVE 部署边界全部通过。
2. `run.ps1 --smoke-test --smoke-result build\client-1.0-smoke.json`：桥接、DPAPI、按钮禁用、响应、窗口关闭和外部导航检查通过。
3. `build-windows.ps1`、`build-installer.ps1`：EXE/ZIP/安装器版本一致，保留既有 AppId、互斥锁、图标及用户目录；原来的 0.2 安装包不会自动变为 1.0。
4. `python -m tools.check_readonly_connection` 和 `python -m tools.check_live_webview`：真实正式只读验证，不提交订单。

## 一次性 Windows VM

VM 使用微软官方 Windows 11 企业评估镜像，4 GB 内存、2 vCPU、64 GB 动态磁盘。主机空闲内存不足约 4.5 GB 时不得启动；不得停止现有服务器来腾出内存。Hyper-V 安装与必要重启由用户在管理员 PowerShell 执行，脚本先明确影响。

准备 VM 干净快照后，逐项记录：安装/普通用户启动、已有运行时、缺运行时离线安装、运行时失败停止、真实 0.2 到 1.0 升级、同版修复、禁止降级、运行中覆盖拒绝、卸载重装、DPAPI 私钥和 SQLite 未确认请求保留。没有完成对应步骤不能记 PASS。

第二机器身份使用 VM 中新生成的 P-256 密钥，单独注册 clientId；不复制当前 Windows 的 DPAPI 私钥。先只读批准，验证账户归属、鉴权拒绝及撤权后的 HTTP/WS 拒绝。
