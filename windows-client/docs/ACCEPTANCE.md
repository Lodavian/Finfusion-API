# 逐步验收说明

## 自动化测试

在项目目录运行 `run-tests.ps1 -q`。独立模拟服务器只绑定 127.0.0.1，使用临时生成的测试密钥及请求记录；没有 Webull SDK 或真实券商凭据。预期所有测试通过，XML 证据保存到 build/test-results.xml。失败时停止打包，修复客户端或模拟契约，禁止用实盘验证替代测试。

覆盖签名原始字节、中文及特殊查询编码、HTTP/WebSocket 权限拒绝、TLS 证书失败、重定向拒绝、超时和 500 不重发、程序重启只查询、双击只创建一个请求、账户隔离、事件断线补查、版本去重、未确认改单/撤单、DPAPI、安全目录及单实例。

## 开发及打包窗口

1. 运行 `run.ps1`。预期出现原生桌面窗口，初始未连接、交易按钮禁用。程序不自动连接或提交交易。若没有窗口或出现异常，停止联调。
2. 生成密钥、导出公钥；预期数据目录只有 DPAPI 加密私钥，没有明文 private.pem，界面不显示私钥。输入无效 PEM 时不覆盖原密钥。
3. 保存配置；预期显示配置已保存、未连接。故意填写错误 clientId 或未获批准的公钥，预期鉴权拒绝，不显示连接成功。
4. 运行 `build-windows.ps1`，解压生成 ZIP 到新目录，双击 FinfusionClient.exe。预期无需项目 Python 即可打开；移动后仍能启动，不读取旧项目目录。
5. `run.ps1 --smoke-test --smoke-result build/dev-smoke.json` 会用临时数据打开真实窗口并自动关闭，不连接任何服务器。打包 EXE 支持同样的 smoke 参数。检查 guiOpened=true、tradeDisabledBeforeAuth=true、noNetworkConnection=true。

## 正式服务器只读联调（待执行）

1. 管理员准备正式 HTTPS API，登记本客户端公钥、返回 clientId，并批准读取权限。点击连接后预期显示签名鉴权成功。
2. 零账户显示无授权账户；单账户自动选择；多个账户必须选择。切换账户后旧数据立即清空，迟到响应不得回填。
3. 手动查询持仓、购买力、订单及详情；仅显示服务器真实字段，购买力 null 不显示成 0。403 或接口未开放时显示明确错误。
4. 观察事件连接，断线后查询补齐订单，原始状态码同时显示。全局交易开关关闭或 readyz=503 时不能声称交易就绪。

当前连接验证服务未开放完整接口，所以不能通过它完成全部只读联调。真实交易及 Webull Sandbox/LIVE 验收尚未执行；LIVE 需要另行明确授权，不在本次自动化验收中。
